The solution is wallet aware attribution.

We connect off chain identifiers to on chain addresses.

This creates a complete picture of the user journey.

The process of the on chain conversion pixel is straightforward.

First, the user clicks an advertisement.

The system captures the standard tracking parameters.

Second, the user connects their wallet to the platform.

A signature request links the cookie identifier to the wallet address.

Third, the user performs a transaction on the ledger.

They might buy an NFT or swap a token.

Fourth, this event is pushed back to the advertising platform.

It is recorded as a purchase conversion.
